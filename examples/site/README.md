# Site Resource Examples

This directory contains examples demonstrating how to create and manage Webflow sites using Pulumi in all supported languages.

## What You'll Learn

- Create Webflow sites with the required properties (`workspaceId`, `displayName`)
- Implement multi-environment site configurations
- Use the optional `parentFolderId`, `templateName` and `publish` inputs
- Read Webflow-generated values (`shortName`, `timeZone`, `previewUrl`, ...) as outputs
- Manage site lifecycle (create, update, delete)

## Available Languages

| Language   | Directory    | Entry Point    | Dependencies        |
|------------|--------------|----------------|---------------------|
| TypeScript | `typescript/`| `index.ts`     | `package.json`      |
| Python     | `python/`    | `__main__.py`  | `requirements.txt`  |
| Go         | `go/`        | `main.go`      | `go.mod`            |
| C#         | `csharp/`    | `Program.cs`   | `.csproj`           |
| Java       | `java/`      | `App.java`     | `pom.xml`           |

## Prerequisites

- Site creation through the Webflow API requires an **Enterprise workspace**
- An API token with the `sites:read` and `sites:write` scopes, set via `pulumi config set webflow:apiToken --secret` or `WEBFLOW_API_TOKEN`

## Quick Start

### TypeScript

```bash
cd typescript
npm install
pulumi stack init dev
pulumi config set workspaceId "YOUR_WORKSPACE_ID"
pulumi config set displayName "My Site"
pulumi up
```

## Examples Included

### 1. Basic Site Creation

Create a simple site with the required properties.

```typescript
const basicSite = new webflow.Site("basic-site", {
    workspaceId: "YOUR_WORKSPACE_ID",
    displayName: "My Website",
});

// Values generated by Webflow are available as read-only outputs:
export const shortName = basicSite.shortName;   // URL slug derived from displayName
export const timeZone = basicSite.timeZone;
```

### 2. Multi-Environment Configuration

Create sites for different environments (development, staging, production).

```typescript
const environments = ["development", "staging", "production"];
const sites = environments.map(env =>
    new webflow.Site(`site-${env}`, {
        workspaceId: "YOUR_WORKSPACE_ID",
        displayName: `My Site - ${env}`,
    })
);
```

### 3. Optional Configuration

Demonstrates the optional inputs: `parentFolderId`, `templateName` (immutable - changing it
replaces the site) and `publish`.

## Configuration

Each example reads the following project config keys:

| Config Key        | Required | Description                                                       |
|-------------------|----------|-------------------------------------------------------------------|
| `workspaceId`     | Yes      | Webflow workspace ID where the site will be created               |
| `displayName`     | Yes      | Human-readable name for the site                                  |
| `parentFolderId`  | No       | Workspace folder to place the site in                             |
| `templateName`    | No       | Site template; immutable, changing it replaces the site           |

**Note:** `shortName` is no longer an input (removed in v0.9.4). Webflow derives it from
`displayName`; read it from the resource output instead (`site.shortName` in TypeScript,
`site.short_name` in Python, `site.ShortName` in Go/C#, `site.shortName()` in Java).
`timeZone` is likewise a read-only output reflecting the timezone configured in Webflow.

## Cleanup

To remove all created sites:

```bash
pulumi destroy
pulumi stack rm dev
```

## Troubleshooting

### "Invalid workspace ID" Error

The workspace ID must be a valid Webflow workspace ID. You can find your workspace ID in the Webflow dashboard under Account Settings > Workspace. Note that an Enterprise workspace is required for site creation via the API.

### "Quota exceeded" Error

You've reached the maximum number of sites for your Webflow plan. Upgrade your plan or delete unused sites.

### Importing an existing site

See [docs/IMPORTING.md](../../docs/IMPORTING.md) to adopt sites created in the Webflow UI.
